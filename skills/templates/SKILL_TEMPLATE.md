# Tool Skill Template

## Purpose
State the decision job this PRAXIS tool performs.

## When To Use
Use when the active case, user role, and context snapshot match the tool contract.

## When Not To Use
Do not use when the request needs a different ontology, direct graph mutation, or unsupported claims.

## Inputs
Describe required and optional input fields.

## Outputs
Describe generated artifacts, claims, tables, memos, or graph proposals.

## Context Requirements
List User, Workspace, Case, and Conversation context needs.

## Composition
List compatible upstream and downstream tools.

## Examples
Provide one short example invocation.

## Pitfalls
Call out common overreach, missing evidence, and confidence warnings.
