# Output Refiner

## Purpose
Refine a tool output to match user role, mandate, communication style, and confidence tolerance.

## When To Use
Use after analytical tools produce rough structured output.

## When Not To Use
Do not add new factual claims or suppress uncertainty.

## Inputs
Tool output, ContextSnapshot, desired artifact type, and citation map.

## Outputs
Edited summary, tightened sections, and explicit uncertainty notes.

## Context Requirements
Needs User preferences and Case context; Workspace style guides improve quality.

## Composition
Follows most analysis tools and can feed Memo Drafter or Brief Exporter.

## Examples
Convert a coalition map output into concise diplomat-ready language.

## Pitfalls
Do not trade precision for polish.
