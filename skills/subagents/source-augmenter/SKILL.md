# Source Augmenter

## Purpose
Suggest additional source receipts or reference material for a thin tool context.

## When To Use
Use when a tool needs external references, workspace methodology, or missing source diversity.

## When Not To Use
Do not use to claim facts without receipts or to mutate the graph.

## Inputs
ContextSnapshot, source gap notes, query terms, and cost ceiling.

## Outputs
Ranked source suggestions with provenance and confidence.

## Context Requirements
Needs case frame and source coverage; benefits from workspace guidelines.

## Composition
Often follows Context Preparer and feeds Brief Exporter, Fact-Check Traceback, or Memo Drafter.

## Examples
Find reference material for a UN mandate traceback with weak source coverage.

## Pitfalls
Separate suggested sources from accepted evidence.
