# Leverage Trace

## Purpose
Trace pressure points from actors to constraints, interests, and concessions.

## When To Use
Use for conflict cases where the user needs leverage paths and negotiable pressure points.

## When Not To Use
Do not use for pure narrative fact checking or source ingestion.

## Inputs
Prompt, active case context, graph snippets, and optional focused actor.

## Outputs
Leverage paths, confidence notes, and cited analytical artifacts.

## Context Requirements
Needs User role/preferences, Workspace methodology when available, and a conflict-oriented case graph.

## Composition
Can chain into Brief Exporter and Contradiction Finder.

## Examples
Trace leverage around a ceasefire-monitoring commitment.

## Pitfalls
Do not present inferred concessions as commitments.
