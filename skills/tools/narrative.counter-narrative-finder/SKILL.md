# Counter-Narrative Finder

## Purpose
Find credible counter-frames and evidence requirements.

## When To Use
Use when a narrative frame needs response options.

## When Not To Use
Do not use to produce unsourced messaging.

## Inputs
Target frame, audience, constraints, and source receipts.

## Outputs
Counter-frame options, risks, and evidence needs.

## Context Requirements
Needs narrative context, user communication style, and source coverage.

## Composition
Can consume Frame Cascade and feed Brief Exporter.

## Examples
Find response frames for a disinformation narrative.

## Pitfalls
Avoid manipulative or unsupported messaging.
