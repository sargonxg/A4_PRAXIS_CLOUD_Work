# Commitment Check

## Purpose
Assess whether a proposed commitment is monitorable, enforceable, and grounded.

## When To Use
Use when drafting or reviewing ceasefire, mandate, or compliance language.

## When Not To Use
Do not use for broad scenario projection.

## Inputs
Proposed commitment text, case context, graph snippets, and source receipts.

## Outputs
Monitorability score, enforcement gaps, and evidence notes.

## Context Requirements
Needs User preferences, Case claims/events/commitments, and optional Workspace methodology.

## Composition
Can chain into Brief Exporter and Contradiction Finder.

## Examples
Check whether a humanitarian access pledge has verifiable milestones.

## Pitfalls
Avoid legal certainty when evidence is incomplete.
