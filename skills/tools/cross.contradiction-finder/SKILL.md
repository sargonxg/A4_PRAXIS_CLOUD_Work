# Contradiction Finder

## Purpose
Find contradictory claims across graph, sources, and generated artifacts.

## When To Use
Use before memos, briefs, or high-confidence analysis.

## When Not To Use
Do not use as a source discovery tool.

## Inputs
Context dump, graph claims, source receipts, and prior tool outputs.

## Outputs
Contradiction clusters, confidence notes, and suggested follow-ups.

## Context Requirements
Needs case claims and provenance; user context improves prioritization.

## Composition
Can consume outputs from most tools and feed Brief Exporter.

## Examples
Find incompatible claims before exporting a policy memo.

## Pitfalls
Contradiction is not the same as deception.
