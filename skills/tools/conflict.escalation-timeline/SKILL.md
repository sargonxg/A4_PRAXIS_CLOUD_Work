# Escalation Timeline

## Purpose
Build a sourced escalation and de-escalation chronology.

## When To Use
Use when timing, sequence, and event causality matter.

## When Not To Use
Do not use when the case has no event evidence.

## Inputs
Prompt, event nodes, source receipts, and temporal constraints.

## Outputs
Timeline, event gaps, and confidence notes.

## Context Requirements
Needs Case event coverage and source provenance; Workspace guidance is helpful.

## Composition
Can chain into Scenario Projector and Brief Exporter.

## Examples
Order escalation events before a Security Council update.

## Pitfalls
Do not infer causality from chronology alone.
