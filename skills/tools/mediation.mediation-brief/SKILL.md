# Mediation Brief

## Purpose
Produce a mediator-ready brief with parties, issues, options, and risks.

## When To Use
Use before a mediation session or shuttle round.

## When Not To Use
Do not use when the user needs a strict policy memo template.

## Inputs
Prompt, case graph, party notes, sources, and prior tool outputs.

## Outputs
Brief sections, issue map, and next-step recommendations.

## Context Requirements
Needs User role, Case actors/claims/interests, and optional Workspace methodology.

## Composition
Can consume Position vs Interest and ZOPA Finder outputs.

## Examples
Draft a mediation brief for a workplace dispute case.

## Pitfalls
Keep party-neutral wording.
