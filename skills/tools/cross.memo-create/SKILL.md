# Memo Create

## Purpose
Create a memo draft from selected case context, accepted tool outputs, and visible citation gaps.

## When To Use
Use when the user has enough graph, source, or tool-run context to start a briefing memo in Memo Studio.

## When Not To Use
Do not use as a substitute for accepting graph claims or source candidates through review.

## Inputs
Case frame, selected graph context, accepted tool outputs, memo template preference, analyst notes, and citation gaps.

## Outputs
Memo outline, draft blocks, citation-gap notes, review notes, and export-readiness posture.

## Context Requirements
Needs user writing preferences, current case context, source receipts when available, and selected tool artifacts.

## Composition
Can consume outputs from marketplace tools and feed Memo Studio, Fact-Check Traceback, or Brief Exporter.

## Examples
Draft a mediation summary memo from accepted ZOPA, position-interest, and fact-check outputs.

## Pitfalls
Do not hide weak citations, silently promote synthesized claims, or overwrite user-authored memo text.
