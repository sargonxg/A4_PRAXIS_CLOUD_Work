## Architectural decisions held this sprint

These are deliberate "not now" calls so the sprint doesn't sprawl:

1. **No new graph backend.** Firestore is the canonical near-term store. Neo4j/FalkorDB/TrustGraph stay optional integrations behind capability flags. Promote later only when a tool can demonstrate concrete traversal value the Firestore-shaped graph can't deliver.
2. **No MCP server yet.** Listed for Week 6 in `docs/STRATEGY.md`. We need the existing tools at READY first; an MCP server that exposes PARTIAL tools would just propagate the gaps.
3. **No new AI provider.** Claude is already optional via `getAnalysisModel()` fallback. Don't add OpenAI / Mistral / Cohere this sprint.
4. **No tool registry rewrite.** Audit confirmed IDs match across registry, route, sidebar, persistence. Day 5 of the prior workplan can be considered closed.

## Risks and how we'll see them early

| Risk | Early signal | Mitigation |
|---|---|---|
| Persistence retrofits break existing tool output reads | `vitest run` failures in `tests/unit/lib/firebase/*` | Each PARTIAL → READY commit must run tests + manually open the tool with an existing situation that has prior output. |
| Audience-tone changes drift outputs in production | Post-deploy `/api/ai/auto-briefing` qualitative regressions | Stream A Day 2 should ship behind a feature flag (`PRAXIS_AUDIENCE_TUNED_BRIEFING=1`) for staging-only initially. |
| ACLED rate limits surprise us | `429` in `/api/health/feeds` after activation | Honour the academic 1-req-per-12-second hint already in `acled-client.ts`; cache aggressively. |
| Onboarding skip path silently regresses | New users hit `/app/dashboard` without profile gate | Stream A Day 5 wires version snapshot on skip and a unit test in `tests/unit/lib/firebase/analyst-profile-admin.test.ts`. |
