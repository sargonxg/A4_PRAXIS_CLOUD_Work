# PRAXIS Roadmap v1.1 And Beyond

Date: 2026-05-06

## v1.1 - Next 60 Days

| Item | Rationale | Effort | Dependency |
|---|---|---:|---|
| Memo citation resolution and export styling | Hardens current Markdown/DOCX/PDF draft export into signed meeting-ready artifacts. | M | Memo persistence API |
| Tool execution handlers for marketplace | Turns the 16-tool registry into a working app surface. | XL | DIALECTICA recipes |
| Context Preparer LangGraph runtime | Turns advisory context gaps into confirmed prepared bundles. | L | ContextProvider packets |
| Postgres KG production cutover | Applies migrations, loads sample cases, and switches ingestion reads to repositories. | XL | Cloud SQL migration |
| Seven-panel diagnostics | Gives operators useful red/yellow/green state. | L | Metrics aggregation |
| Graph edit round-trip | Makes graph canvas operational, not just read-only. | XL | KG repository layer |
| Drag/drop document upload | Expected first-week user request. | M | Existing document APIs |
| Citation auto-suggest | Reduces memo friction. | M | Graph search |

| Bulk node editing | Needed once ingestion volume grows. | M | Graph edit APIs |

## v2 - 3 To 6 Months

- Multi-tenant teams and shared cases.
- Custom user-authored ontologies.
- Real-time ingestion sources.
- Neo4j revival for graph algorithms if traversal needs outgrow Postgres.
- Memo collaboration with comments and suggestions.
- Mobile read-only workbench.
- External webhooks and Slack notifications.

## v3 - 6 To 18 Months

- UN language coverage.
- Public read-only case sharing.
- White-label deployments for institutions.
- Agentic chains that propose next tools or memo sections.
- Low-bandwidth field deployment profile.
- Third-party/user-authored tools marketplace.
- Advanced analytics dashboards.
