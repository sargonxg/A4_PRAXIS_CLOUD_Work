# Capsule inspection and memo handover

The default capsule inspector is one native modal dialog with Overview, Evidence, Timeline and Review tabs. Purpose and a responsive evidence map appear first. Recorded claims, exact captured source excerpts, review decisions and version metadata remain inspectable; deeper ontology, memory, research, history and output contracts stay in expandable sections.

Opening an inspector does not attach its capsule to chat. The owned saved capsule's **Use in chat** action opens `/app?capsuleId=ID`, leaving canonical owner/version resolution and persistence to the chat route. The native dialog supplies background inertness and focus trapping; cleanup restores focus and body scrolling. Visibility and context scope are separate labels. Map claim actions select, open, focus and highlight the exact receipt.

The map has a complete native-button list for all nodes and relationships, independent of the spatial projection's deduplication and large-graph grouping. Selecting a grouped item expands it in the map. Detail metadata resolves against the currently supplied version. Missing excerpts, confidence and rationale remain explicit. Canvas resizing follows its measured container and graph controls honor reduced motion.

Memo handover uses GET to inspect the exact saved package, then an explicit POST with the preview digest to create temporary bearer access. A stale response refreshes the preview for another deliberate click. Review scope is stated as internal analysis, external sharing or publication; it does not independently approve capsule/source dependencies. Included material, omissions, recipient-access gaps and limitations remain visible.

Saved memo context comes from the server-named immutable version's complete validated context snapshot. Case IDs, block metadata and the currently open chat cannot establish its pin. Detached drafts stay detached. Ordinary edits to legacy drafts omit context fields and keep their legacy-unbound status. An explicit **Use no capsule for this memo** recovery choice clears old source references and invalidates the saved boundary until Save records the choice.
