# OpenSanctions Data Licensing

## Development And Evaluation

PRAXIS can use the public OpenSanctions archive for development, evaluation,
and non-commercial testing. The integration code path uses yente,
FollowTheMoney, and Rigour, which are permissively licensed.

## Commercial Production

Before PRAXIS serves paying commercial customers with OpenSanctions-derived
data, TACITUS should procure the appropriate OpenSanctions commercial data
subscription.

Procurement contact: `contact@opensanctions.org`

## Engineering Boundary

The code ships independently of the data subscription. Production configuration
must make the active data source explicit and must not mix development archive
data with commercial customer claims without approval.
