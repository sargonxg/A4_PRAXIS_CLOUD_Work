## Phase 3 — Tools (top 10)

For each top-10 tool, test the four canonical paths:

1. **No situation** → `<NoSituationState />` renders, generation is blocked.
2. **Onboarding incomplete** → `<OnboardingRequiredState />` renders.
3. **Live mode with situation** → tool generates structured output, persists, reload restores.
4. **Demo mode** → fixture renders without making any AI calls.

| Tool | Live happy-path | Live cold-reload | Demo fixture | Calibration check |
|---|---|---|---|---|
| Ask PRAXIS (chat) | streaming response cites corpus items by `[#n]` (Lane N) | conversation lost on tab close (TODO BIG #1) | demo greeting cached response | exempt — `chat` is on the audit exempt list |
| Daily Brief | structured `AutoBriefing` saves under `tools/daily_brief` | reload reads from `tools/daily_brief` (id drift TODO) | Nordalia fixture | `withCalibration('daily_brief', 'ai_report')` |
| Briefing Room | 7 slides save | reload reads (id drift `briefing` vs `briefing_room` TODO) | Nordalia fixture | `withCalibration('briefing_room', 'ai_report')` |
| Risk Monitor | 5-region INFORM scoring | reload reads from `tools/risk_assessment` | Nordalia fixture | `withCalibration('risk_assessment', 'ai_risk_assessment')` |
| Early Warning | escalation scan output | reload reads (id drift TODO) | demo `_demo.tsx` shell | `withCalibration('escalation_scan', 'ai_analysis')` |
| Humanitarian | `HumanitarianSnapshotSchema` saves under `tools/humanitarian` | **NEW (Lane B)** — reload reads structured snapshot once page wires the route in Lane G | demo fixture w/ "Demo data" badge (TODO add badge) | `withCalibration('humanitarian', 'ai_humanitarian')` |
| Brainstorming Table | 5–7 turns + synthesis save under `tools/brainstorming-table` | **NEW (Lane C)** — reload reads via `useToolData('brainstorming-table')` | demo fixture | `withCalibration('brainstorming-table', 'ai_brainstorming_table')` |
| Negotiation Prep | ZOPA/BATNA save under `tools/negotiation_prep` | reload reads | Nordalia fixture | `withCalibration('negotiation_prep', 'ai_analysis')` |
| Conflict Graph | extracted nodes + edges | reload reads (id drift TODO) | Nordalia fixture | `withCalibration('conflict_graph', 'ai_analysis')` |
| Legal Tracker | per-resolution compliance | reload reads from `tools/legal-tracker` | Nordalia fixture | `withCalibration('legal_tracker', 'ai_legal_tracker')` (fixed ninth session) |

**Per-tool failure modes to test:**

- Feed timeout (HDX HAPI / ReliefWeb): tool degrades to AI-only,
  intelligenceGaps populated, no fictional figures in `!isDemo`.
- Pro model hits quota: route returns 503 without leaving a half-saved
  doc in Firestore.
- Profile version stale (between tool generation and persistence):
  `saveToolOutput` writes `profileVersion` from `provenance` — verify
  by mutating profile mid-flight.
- Demo flag drift: `isClientDemoMode()` and `isServerDemoMode()`
  must agree. Test by setting one and not the other (server-side
  cookie present but client-side `isDemo` false).

## Cadence

- **Per deploy** (every push to main that triggers Cloud Build):
  Phase 6 smoke + a single-tool Phase 3 spot-check.
- **Per major brick**: relevant phase + persona walkthrough addendum
  in `docs/personas/`.
- **Weekly**: full Phases 1–4 against the canonical test accounts.
- **Monthly**: Phase 5 spine review + TTL retention spot-check.

When a test fails, file the failure in `docs/TODO_BOARD_2026-04-26.md`
with the failing step number and the persona, then open a brick to fix
it (or recover if it's a regression from a recent commit).
