# Tools used

| tool | mode | purpose |
|---|---|---|
| ripgrep | installed | search and route/env scans |
| madge | npx --yes | TypeScript dependency graph and circular dependency check |
| depcheck | npx --yes | frontend dependency usage candidates |

| jscpd | npx --yes | clone detection |
