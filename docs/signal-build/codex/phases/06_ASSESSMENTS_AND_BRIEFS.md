# Phase 06 - continuing assessments and deliverable briefs

Additional required reading: [research/UI_BRIEF_SPEC.md](../../research/UI_BRIEF_SPEC.md), [research/ANALYTICAL_METHOD.md](../../research/ANALYTICAL_METHOD.md). Use these as design inputs; verify current provider/repository contracts in this checkout.

Implement the primary value: an assessment delta since the last approved desk output. A delta names the old conclusion, new evidence, changed interpretation, unchanged findings, unresolved alternatives and decision implications. It references exact claim/source/context revisions and the rule or distinction used. A new mention count alone cannot manufacture a change in geopolitical risk.

Provide narrative dossiers with a frame, linked attributed claims, observed circulation, independent-evidence groups, contrary observations, alternatives and explicitly qualified judgments. Provide actor-position comparison based on dated quotations and translations. Reuse the existing PRAXIS output/memo workflow and Output capsule rather than adding a disconnected document subsystem.

Separate generated draft, human-edited revision and approved artifact. Bind approval to a manifest of text digest, source revisions, claims, context/compiler receipts, reviewer and export policy. Editing any approved text creates a new draft. New evidence flags possible staleness without modifying the historical brief. If a reviewer approves an unresolved-source interpretation, the uncertainty must remain explicit in the output.

Create exportable weekly country/theatre brief, narrative dossier and portable capsule/evidence manifest. Quotes and media obey their retention/redistribution entitlements. Use source locators and numbered evidence references; no fabricated citations. A referenced source must be accessible to the recipient or shown as restricted without leaking it. The live UI links to the exact approved artifact, not a mutable preview.

Acceptance: run the synthetic policy-proposal fixture: accepted source reading, reviewed contextual distinction, later revision and reopened assessment. The delta explains what changed without turning welcome into adoption. Rejected claims do not appear as accepted facts. Export pinning, approval invalidation on edits, rights restrictions and contradictory evidence are tested. Show the same workflow for another country and a cross-border theatre. Record actual end-to-end evidence, not only snapshot tests.
