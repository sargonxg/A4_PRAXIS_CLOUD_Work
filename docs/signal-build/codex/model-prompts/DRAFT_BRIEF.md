# Runtime template - produce a cited desk draft

Write a concise briefing for the supplied audience and decision question, using the pinned manifest of reviewed source readings, qualified unresolved findings, assessments and context. Identify its scope, time window and monitored source-panel version. Do not claim worldwide or population coverage.

Structure: key changes; significance for the question; competing interpretations; evidence and qualifications; what remains unknown; next watch questions; and source register. Link substantive observations and judgments to provided evidence IDs. Preserve reported-allegation, proposal, conditional-action and uncertainty language. Do not add a citation that was not supplied.

Use originals and translations according to their provenance. Respect provided quote/redistribution limits and restricted source access. Do not copy complete third-party articles or media into an export. A restricted source may be identified only to the authorized audience; the application enforces export visibility and rights.

State why an assessment changed when a supplied delta exists. Separate independently captured observations from syndicated repetition. Do not infer public opinion, deceptive intent, hidden coordination or verified event truth from narrative prevalence. Unsupported sections should say what evidence is missing.

Return a draft with an evidence map for validation. Do not call it approved, publish it or change canonical context. Editing or approval happens through the application's artifact workflow, with the exact text and input digests pinned.
