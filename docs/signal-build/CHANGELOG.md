# Build kit release notes

## 0.2 - expanded research and portable entry

Prepared 5 October 2026. Supersedes the earlier 0.1 handoff.

- Added `BOOTSTRAP.md` so Codex can start from any accessible extraction folder, locate the real PRAXIS repository, install the kit and resume an existing checkpoint.
- Added a PowerShell launcher that resolves its own kit path and runs Codex against the specified repository without copying or deploying anything.
- Added research on multilingual retrieval, stable narrative identities, persuasion/framing evaluation, provider country codes, source access, temporal context and customer briefs.
- Added pure reference utilities and regression tests for exact evidence locators, embedding compatibility, panel-qualified attention changes and artifact dependency invalidation.
- Added a machine-readable primary-source register and source-access planning matrix. External models/datasets and restricted data are linked, not bundled or claimed licensed.
- Updated the project report, phase reading requirements, manifest and archive verification.

The production route, native capsule integration, live collectors, real model inference and Cloud development environment remain unimplemented/unverified by this reference package. PowerShell scripts have not been executed on Windows here. The package documents those gates rather than marking them passed.
