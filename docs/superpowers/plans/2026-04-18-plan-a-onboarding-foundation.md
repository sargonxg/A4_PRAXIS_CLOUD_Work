# Plan A — PRAXIS User Onboarding Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the first-login AnalystProfile onboarding flow plus the shared `withCalibration` middleware and `buildCalibratedContext` module that every AI route will consume, so every downstream tool fix in Plan B has a working calibration contract to snap onto. Also produce the tool audit script + first-run report that drives Plan B's fix ordering.

**Architecture:** Firestore-backed `users/{uid}/profile/analyst` doc captured in a 3-screen wizard at `/onboarding`. Profile is versioned in a subcollection. A single `buildCalibratedContext(uid, situationId, toolId)` function reads profile + situation + SKC and returns a context block. `withCalibration` middleware wraps `withAuth + withCredits` and injects that block into every AI route handler. Profile updates publish to Pub/Sub `profile.events` which refreshes the Vertex embedding cached on the profile doc. Middleware at `/app/*` redirects first-login users to `/onboarding` and renders a persistent "complete your profile" banner if skipped.

**Tech Stack:** Next.js 16 App Router, Firebase Admin SDK (server) + client SDK (UI), Firestore, Firestore Vector Search (KNN), Vertex AI (gemini-embedding-2-preview), Cloud Pub/Sub, Cloud Tasks, Zod, Vitest, Playwright, Tailwind CSS, Framer Motion, `@dnd-kit/sortable` (new dep for lens reorder).

**Spec:** `docs/superpowers/specs/2026-04-18-user-onboarding-tool-calibration-design.md`

**Scope:** Phases P1-P4 only (P5+ = Plan B, written after the audit report from P4 exists).

## Tech notes (read before starting)

- Codebase uses **`withAuth` and `checkAndDeductCredits`** as separate helpers, not composed. Standard pattern is `withAuth(async (req, user) => { const gate = await checkAndDeductCredits(opType, desc); if (!gate.allowed) return gate.response; ... })`. Our new `withCalibration` will preserve that — it is a factory that returns a handler pre-wrapped by `withAuth` and that internally calls `checkAndDeductCredits`.
- Server-side Firestore uses `firebase-admin` (`getAdminDbOrThrow()` from `@/lib/firebase/admin`). Client uses `firebase` (`db` from `@/lib/firebase/config`). Both services (`analyst-profile-service.ts` client, `analyst-profile-admin.ts` admin) exist to avoid mixing SDKs in either layer.
- Embedding model lives in `src/lib/knowledge/embedding-service.ts` via `getEmbeddingModel()` (`gemini-embedding-2-preview`). It returns `null` when unavailable — always null-check.
- Vitest is the test runner (already installed, `vitest.config.ts` exists). Import form: `import { describe, it, expect, vi } from 'vitest'`.
- Session cookie is `tacitus-auth-session`, signed via `src/lib/auth/cookie-signer.ts`. Edge-middleware parses it for routing; full HMAC verify happens in `with-auth.ts`.
- Middleware runs on Edge runtime — **no** Node `crypto`, **no** Admin SDK. For first-login detection we piggyback on a small header set by `/api/auth/session` when it creates the cookie: `onboarded=1` encoded into cookie JSON. Simplest path. No extra Firestore read in middleware.
- Pub/Sub client: use `@google-cloud/pubsub`. If not yet installed, add it in P1.
- Drag reorder: `@dnd-kit/core` + `@dnd-kit/sortable`. Not yet in deps — add in P1.
- Profile doc path: `users/{uid}/profile/analyst` (subcollection `profile`, doc id `analyst`). Versions: `users/{uid}/profile/analyst_versions/{versionId}` — Firestore doesn't allow subcollections under a specific doc in every SDK cleanly across client/admin — we flatten to a sibling doc with prefix + subcollection as `users/{uid}/profile_versions/{versionId}` to stay safe. Final path:
  - Live: `users/{uid}/profile/analyst`
  - Versions: `users/{uid}/profile_versions/v{n}`

```ts
import { z } from 'zod';

export const LENSES = [
  'diplomatic',
  'security',
  'humanitarian',
  'economic',
  'legal_ihl',
  'human_rights',
  'development',
  'mediation',
  'climate_security',
] as const;

export type Lens = typeof LENSES[number];

export const ROLES = [
  'un_official', 'diplomat', 'think_tank', 'ngo', 'researcher',
  'journalist', 'private_sector', 'other',
] as const;
export type AnalystRole = typeof ROLES[number];

export const SENIORITIES = ['junior', 'mid', 'senior', 'executive'] as const;
export type Seniority = typeof SENIORITIES[number];

export const AUDIENCES = ['myself', 'team', 'senior_leadership', 'external_partners', 'public'] as const;
export type Audience = typeof AUDIENCES[number];

export const LANGUAGES = ['en', 'fr', 'es', 'ar', 'ru', 'zh'] as const;
export type Language = typeof LANGUAGES[number];

export const ANALYTICAL_STYLES = ['rapid_brief', 'deep_dive'] as const;
export type AnalyticalStyle = typeof ANALYTICAL_STYLES[number];

export const AnalystProfileSchema = z.object({
  identity: z.object({
    role: z.enum(ROLES),
    seniority: z.enum(SENIORITIES),
    org: z.string().max(120),
    team: z.string().max(120),
  }),
  perspective: z.object({
    mandate: z.string().max(600),
    lenses: z.array(z.enum(LENSES)).min(1).max(5),
    regions: z.array(z.string().max(80)).max(8),
    audience: z.enum(AUDIENCES),
  }),
  workingStyle: z.object({
    sourceCategories: z.array(z.string()).max(16),
    language: z.enum(LANGUAGES),
    redLines: z.array(z.string().max(240)).max(12),
    analyticalStyle: z.enum(ANALYTICAL_STYLES),
  }),
  meta: z.object({
    version: z.number().int().nonneg(),
    completedAt: z.any().nullable(),
    lastEditedAt: z.any(),
    skipCount: z.number().int().nonneg(),
    createdAt: z.any(),
  }),
  embedding: z.object({
    vector: z.array(z.number()).length(768).optional(),
    generatedAt: z.any().optional(),
    model: z.string().optional(),
  }).optional(),
});

export type AnalystProfile = z.infer<typeof AnalystProfileSchema>;

export const DEFAULT_ANALYST_PROFILE: AnalystProfile = {
  identity: { role: 'other', seniority: 'mid', org: '', team: '' },
  perspective: { mandate: '', lenses: ['diplomatic'], regions: [], audience: 'myself' },
  workingStyle: {
    sourceCategories: ['foundational', 'conflict-security', 'humanitarian', 'diplomatic-official', 'news-media'],
    language: 'en',
    redLines: [],
    analyticalStyle: 'rapid_brief',
  },
  meta: { version: 0, completedAt: null, lastEditedAt: null, skipCount: 0, createdAt: null },
};

/** A profile is "complete" only when the required perspective fields and identity are filled. */
export function isProfileComplete(p: AnalystProfile): boolean {
  return (
    p.identity.role !== 'other' || p.identity.org.trim().length > 0
  ) && p.perspective.mandate.trim().length >= 30
    && p.perspective.lenses.length >= 1
    && p.perspective.regions.length >= 1
    && !!p.perspective.audience;
}
```

```ts
import { FieldValue } from 'firebase-admin/firestore';
import { getAdminDbOrThrow } from './admin';
import { DEFAULT_ANALYST_PROFILE, type AnalystProfile } from '@/types/analyst-profile';

const USERS = 'users';
const PROFILE = 'profile';
const PROFILE_DOC = 'analyst';
const VERSIONS = 'profile_versions';

export async function getAnalystProfile(uid: string): Promise<AnalystProfile | null> {
  const db = getAdminDbOrThrow();
  const ref = db.collection(USERS).doc(uid).collection(PROFILE).doc(PROFILE_DOC);
  const snap = await ref.get();
  if (!snap.exists) return null;
  return snap.data() as AnalystProfile;
}

/**
 * Upserts partial profile fields. Preserves other fields via merge.
 * Updates meta.lastEditedAt. Does NOT bump meta.version (that's completeAnalystProfile).
 */
export async function upsertAnalystProfile(
  uid: string,
  patch: Partial<AnalystProfile>,
): Promise<void> {
  const db = getAdminDbOrThrow();
  const ref = db.collection(USERS).doc(uid).collection(PROFILE).doc(PROFILE_DOC);
  const snap = await ref.get();
  if (!snap.exists) {
    // First write — seed with defaults
    await ref.set({
      ...DEFAULT_ANALYST_PROFILE,
      ...patch,
      meta: {
        ...DEFAULT_ANALYST_PROFILE.meta,
        createdAt: FieldValue.serverTimestamp(),
        lastEditedAt: FieldValue.serverTimestamp(),
      },
    });
    return;
  }
  await ref.set({
    ...patch,
    meta: { ...(patch.meta ?? {}), lastEditedAt: FieldValue.serverTimestamp() },
  }, { merge: true });
}

/**
 * Bumps meta.version, writes immutable snapshot to profile_versions/{versionId},
 * sets users/{uid}.onboardingCompletedAt. Returns versionId.
 */
export async function completeAnalystProfile(uid: string): Promise<{ versionId: string }> {
  const db = getAdminDbOrThrow();
  const userRef = db.collection(USERS).doc(uid);
  const profileRef = userRef.collection(PROFILE).doc(PROFILE_DOC);

  const snap = await profileRef.get();
  const current = (snap.exists ? snap.data() : DEFAULT_ANALYST_PROFILE) as AnalystProfile;
  const nextVersion = (current.meta?.version ?? 0) + 1;
  const versionId = `v${nextVersion}`;

  // write snapshot
  await userRef.collection(VERSIONS).doc(versionId).set({
    ...current,
    meta: { ...current.meta, version: nextVersion, completedAt: FieldValue.serverTimestamp() },
    _snapshotAt: FieldValue.serverTimestamp(),
  });

  // bump live profile
  await profileRef.set({
    meta: {
      version: nextVersion,
      completedAt: FieldValue.serverTimestamp(),
      lastEditedAt: FieldValue.serverTimestamp(),
    },
  }, { merge: true });

  // set root flag
  await userRef.update({
    onboardingCompletedAt: FieldValue.serverTimestamp(),
  });

  return { versionId };
}

export async function incrementOnboardingSkip(uid: string): Promise<void> {
  const db = getAdminDbOrThrow();
  await db.collection(USERS).doc(uid).update({
    onboardingSkipCount: FieldValue.increment(1),
  });
}
```

```ts
import type { AnalystProfile, Audience, Language, AnalyticalStyle } from '@/types/analyst-profile';
import type { Situation } from '@/types/situation';

export interface RetrievedChunk {
  id: string;
  text: string;
  source: string;
  score?: number;
}

export interface OutputConstraints {
  language: Language;
  audienceTone: Audience;
  redLineClauses: string[];
  styleHint: AnalyticalStyle;
}

export function renderOutputConstraints(profile: AnalystProfile): OutputConstraints {
  return {
    language: profile.workingStyle.language,
    audienceTone: profile.perspective.audience,
    redLineClauses: profile.workingStyle.redLines.filter(Boolean),
    styleHint: profile.workingStyle.analyticalStyle,
  };
}

export function renderSystemPromptBlock(opts: {
  profile: AnalystProfile | null;
  situation: Situation | null;
  retrievedChunks: RetrievedChunk[];
}): string {
  const parts: string[] = [];

  parts.push(renderProfileBlock(opts.profile));
  parts.push(renderSituationBlock(opts.situation));
  if (opts.retrievedChunks.length > 0) {
    parts.push(renderKnowledgeBlock(opts.retrievedChunks));
  }
  parts.push(renderConstraintsBlock(opts.profile));

  return parts.join('\n\n');
}

function renderProfileBlock(p: AnalystProfile | null): string {
  if (!p) {
    return [
      '<analyst-profile version="0">',
      '  No profile set — respond in neutral analytical register, English.',
      '</analyst-profile>',
    ].join('\n');
  }
  const v = p.meta?.version ?? 0;
  const lensLine = p.perspective.lenses.length > 1
    ? `Primary lens: ${p.perspective.lenses[0]}. Secondary: ${p.perspective.lenses.slice(1).join(', ')}.`
    : `Primary lens: ${p.perspective.lenses[0] ?? 'diplomatic'}.`;
  return [
    `<analyst-profile version="${v}">`,
    `  Role: ${p.identity.seniority} ${p.identity.role} at ${p.identity.org || '—'} · ${p.identity.team || '—'}`,
    `  Mandate: ${p.perspective.mandate || '—'}`,
    `  ${lensLine}`,
    `  Regions of focus: ${p.perspective.regions.join(', ') || '—'}`,
    `  Audience: ${p.perspective.audience}`,
    `  Output language: ${p.workingStyle.language}`,
    `  Preferred style: ${p.workingStyle.analyticalStyle}`,
    `  Red lines:`,
    ...(p.workingStyle.redLines.length
      ? p.workingStyle.redLines.map(r => `    - ${r}`)
      : ['    (none specified)']),
    `</analyst-profile>`,
  ].join('\n');
}

function renderSituationBlock(s: Situation | null): string {
  if (!s) return ['<situation-frame>', '  No active situation.', '</situation-frame>'].join('\n');
  return [
    '<situation-frame>',
    `  Name: ${s.name}`,
    `  Type: ${s.type}`,
    `  Region: ${s.region || '—'}`,
    `  Key actors: ${(s.actors ?? []).join(', ') || '—'}`,
    `  Risk: ${s.riskScore ?? '—'}/10 · Glasl ${s.glaslStage ?? '—'} · ${s.escalationTrend ?? '—'}`,
    '</situation-frame>',
  ].join('\n');
}

function renderKnowledgeBlock(chunks: RetrievedChunk[]): string {
  return [
    '<retrieved-knowledge>',
    ...chunks.map(c => `  [${c.id}] ${c.text.slice(0, 500)} — ${c.source}`),
    '</retrieved-knowledge>',
  ].join('\n');
}

function renderConstraintsBlock(p: AnalystProfile | null): string {
  const lang = p?.workingStyle.language ?? 'en';
  const tone = p?.perspective.audience ?? 'myself';
  const style = p?.workingStyle.analyticalStyle ?? 'rapid_brief';
  const redLines = p?.workingStyle.redLines ?? [];
  return [
    '<output-constraints>',
    `  - Respond in ${lang}.`,
    `  - Tone: ${tone} register.`,
    ...redLines.map(r => `  - Constraint: ${r}`),
    `  - ${style === 'deep_dive' ? 'Favor depth, caveats, and citations.' : 'Favor brevity and actionable bullets.'}`,
    '</output-constraints>',
  ].join('\n');
}
```

```ts
  systemPromptBlock: string;
  outputConstraints: OutputConstraints;
  toolContext: {

    situation: Situation | null;

const NEUTRAL_CONSTRAINTS: OutputConstraints = {
  language: 'en',
  audienceTone: 'myself',
  redLineClauses: [],
  styleHint: 'rapid_brief',
};

export async function buildCalibratedContext(opts: {
  uid: string;
  situationId?: string;
  toolId: string;
  retrievalQuery?: string;
  retrievalTopK?: number;

    toolContext: { profile, situation, retrievedChunks },
```

```ts
import { getAnalystProfile } from '@/lib/firebase/analyst-profile-admin';
import { SituationKnowledgeCore } from './situation-knowledge-core';
import type { RetrievedChunk } from '@/lib/context/system-prompt-block';

export async function retrieveForProfile(opts: {
  uid: string;
  situationId?: string;
  query: string;
  topK: number;
}): Promise<RetrievedChunk[]> {
  try {
    const profile = await getAnalystProfile(opts.uid).catch(() => null);
    if (!opts.situationId) return [];

    const skc = new SituationKnowledgeCore(opts.uid, opts.situationId);
    const base = await skc.retrieve(opts.query, opts.topK * 2);

    // No profile embedding → return base order
    const profileVec = profile?.embedding?.vector;
    if (!profileVec || profileVec.length === 0) {
      return base.slice(0, opts.topK).map(mapChunk);
    }

    // Rerank by cosine-sim between chunk vector (if present) and profile vector
    const reranked = base
      .map(c => {
        const vec = (c as unknown as { vector?: number[] }).vector;
        const score = vec ? cosine(vec, profileVec) : 0;
        return { ...c, _profileScore: score };
      })
      .sort((a, b) => (b._profileScore ?? 0) - (a._profileScore ?? 0))
      .slice(0, opts.topK);

    return reranked.map(mapChunk);
  } catch (err) {
    console.warn('[profile-weighted-retrieval] fallback:', err);
    return [];
  }
}

function mapChunk(c: unknown): RetrievedChunk {
  const obj = c as { id?: string; text?: string; source?: string; score?: number };
  return {
    id: obj.id ?? 'unknown',
    text: obj.text ?? '',
    source: obj.source ?? 'unknown',
    score: obj.score,
  };
}

function cosine(a: number[], b: number[]): number {
  if (a.length !== b.length) return 0;
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) { dot += a[i] * b[i]; na += a[i] * a[i]; nb += b[i] * b[i]; }
  const denom = Math.sqrt(na) * Math.sqrt(nb);
  return denom === 0 ? 0 : dot / denom;
}
```

```ts
import { PubSub } from '@google-cloud/pubsub';
import { getAnalystProfile, upsertAnalystProfile } from './analyst-profile-admin';
import { generateEmbedding } from '@/lib/knowledge/embedding-service';

const TOPIC_NAME = 'profile.events';
let client: PubSub | null = null;

function getClient(): PubSub {
  if (!client) client = new PubSub();
  return client;
}

export type ProfileEventKind = 'created' | 'updated' | 'completed' | 'skipped' | 'embedding_refreshed';

/**
 * Publishes to profile.events topic. Returns true on success.
 * Never throws — callers must not block on publish success.
 */
export async function publishProfileEvent(event: {
  uid: string;
  kind: ProfileEventKind;
  versionId?: string;
  extra?: Record<string, string>;
}): Promise<boolean> {
  try {
    const data = Buffer.from(JSON.stringify({
      ...event,
      publishedAt: new Date().toISOString(),
    }));
    await getClient().topic(TOPIC_NAME).publishMessage({
      data,
      attributes: {
        uid: event.uid,
        kind: event.kind,
        ...(event.versionId ? { versionId: event.versionId } : {}),
        ...(event.extra ?? {}),
      },
    });
    return true;
  } catch (err) {
    console.warn('[profile-events] publish failed (non-fatal):', err);
    return false;
  }
}

/**
 * Regenerates the profile embedding from mandate + lenses.
 * Called by Pub/Sub subscriber OR lazily by withCalibration when missing.
 */
export async function refreshProfileEmbedding(uid: string): Promise<boolean> {
  const profile = await getAnalystProfile(uid);
  if (!profile) return false;
  const text = [
    profile.perspective.mandate,
    `Lenses: ${profile.perspective.lenses.join(', ')}`,
    `Regions: ${profile.perspective.regions.join(', ')}`,
    `Audience: ${profile.perspective.audience}`,
  ].filter(Boolean).join('\n');
  if (!text.trim()) return false;
  const vector = await generateEmbedding(text);
  if (!vector) return false;
  await upsertAnalystProfile(uid, {
    embedding: {
      vector,
      generatedAt: new Date() as unknown as undefined,  // Firestore serverTimestamp preferred but upsertAnalystProfile merges
      model: 'gemini-embedding-2-preview',
    },
  });
  return true;
}
```

```ts
        output: input.output,
        profileVersion: input.profileVersion,
        metadata: input.metadata ?? {},
        generatedAt: FieldValue.serverTimestamp(),
      }, { merge: true });
```

```ts
import { withAuth, type AuthenticatedUser } from './with-auth';
import { checkAndDeductCreditsForUid } from './with-credits';
import { buildCalibratedContext, type ContextBlock } from '@/lib/context/profile-context';

export interface CalibrationCtx extends AuthenticatedUser {
  calibration: ContextBlock;
}

export type CalibratedHandler = (req: Request, ctx: CalibrationCtx) => Promise<Response>;

/**
 * Wraps a route handler with auth → credits → calibration context injection.
 *
 * @param toolId        canonical tool id (matches tool-registry)
 * @param creditOpType  key into AI_CREDIT_COSTS (e.g. 'ai_risk_assessment')
 * @param opts.retrievalQuery  optional: turns on SKC retrieval for this tool
 */
export function withCalibration(
  toolId: string,
  creditOpType: string,
  opts: { retrievalQuery?: (req: Request, body: Record<string, unknown>) => string | undefined } = {},
) {
  return (handler: CalibratedHandler) => withAuth(async (req: Request, user: AuthenticatedUser) => {
    // Demo users skip credits but still get calibration
    let situationId: string | undefined;
    let body: Record<string, unknown> = {};
    try {
      const raw = await req.clone().text();
      if (raw) body = JSON.parse(raw) as Record<string, unknown>;
      if (typeof body.situationId === 'string') situationId = body.situationId;
    } catch { /* non-JSON body OK */ }

    if (!user.isDemo) {
      const gate = await checkAndDeductCreditsForUid(user.uid, creditOpType, `tool:${toolId}`);
      if (!gate.allowed) return gate.response;
    }

    const retrievalQuery = opts.retrievalQuery?.(req, body);

    const calibration = await buildCalibratedContext({
      uid: user.uid,
      situationId,
      toolId,
      retrievalQuery,
    });

    return handler(req, { ...user, calibration });
  });
}
```

```tsx
'use client';

import { useState } from 'react';
import { Plus, Check, X, Sparkles, Loader2 } from 'lucide-react';
import { cn } from '@/lib/utils/cn';

export interface ChipStackProps {
  label: string;
  helper?: string;
  suggestions: string[];
  value: string[];
  onChange: (next: string[]) => void;
  max?: number;
  allowCustom?: boolean;
  placeholder?: string;
  onRequestMore?: () => Promise<string[]>;  // optional AI chip expansion
}

export function ChipStack({
  label, helper, suggestions, value, onChange,
  max = 8, allowCustom = true, placeholder, onRequestMore,
}: ChipStackProps) {
  const [custom, setCustom] = useState('');
  const [loadingMore, setLoadingMore] = useState(false);
  const [extra, setExtra] = useState<string[]>([]);

  const pool = [...suggestions, ...extra];

  const toggle = (chip: string) => {
    if (value.includes(chip)) {
      onChange(value.filter(v => v !== chip));
    } else if (value.length < max) {
      onChange([...value, chip]);
    }
  };

  const addCustom = () => {
    const c = custom.trim();
    if (!c || value.includes(c) || value.length >= max) return;
    onChange([...value, c]);
    setCustom('');
  };

  const loadMore = async () => {
    if (!onRequestMore) return;
    setLoadingMore(true);
    try {
      const more = await onRequestMore();
      setExtra(prev => [...prev, ...more.filter(m => !prev.includes(m) && !suggestions.includes(m))]);
    } finally {
      setLoadingMore(false);
    }
  };

  return (
    <div className="space-y-2">
      <div className="flex items-baseline justify-between">
        <label className="text-xs font-medium text-navy-700">{label}</label>
        <span className="text-[10px] text-navy-400">{value.length}/{max}</span>
      </div>
      {helper && <p className="text-[11px] text-navy-500">{helper}</p>}

      {/* Selected chips (editable) */}
      {value.length > 0 && (
        <div className="flex flex-wrap gap-1.5 rounded-lg border border-diplomatic-blue/30 bg-diplomatic-blue/5 p-2">
          {value.map((v, i) => (
            <span key={i} className="group inline-flex items-center gap-1 rounded-full bg-white px-2.5 py-0.5 text-[11px] text-navy-800 shadow-sm">
              {v}
              <button onClick={() => onChange(value.filter((_, j) => j !== i))} className="text-navy-400 hover:text-red-500">
                <X className="h-3 w-3" />
              </button>
            </span>
          ))}
        </div>
      )}

      {/* Suggestion pool */}
      <div className="flex flex-wrap gap-1.5">
        {pool.map((s, i) => {
          const active = value.includes(s);
          return (
            <button
              key={i}
              type="button"
              onClick={() => toggle(s)}
              disabled={!active && value.length >= max}
              className={cn(
                'inline-flex items-center gap-1 rounded-full border px-2.5 py-1 text-[11px] transition',
                active ? 'border-diplomatic-blue/40 bg-diplomatic-blue/10 text-diplomatic-blue'
                       : 'border-navy-200 bg-white text-navy-600 hover:border-navy-300',
                !active && value.length >= max && 'opacity-50 cursor-not-allowed',
              )}
            >
              {active && <Check className="h-3 w-3" />}
              {s}
            </button>
          );
        })}

            {loadingMore ? <Loader2 className="h-3 w-3 animate-spin" /> : <Sparkles className="h-3 w-3" />}

          </button>
        )}
      </div>

      {allowCustom && (
        <div className="flex gap-2 pt-1">
          <input
            type="text"
            value={custom}
            onChange={e => setCustom(e.target.value)}
            onKeyDown={e => e.key === 'Enter' && (e.preventDefault(), addCustom())}

            <Plus className="h-3 w-3" /> Add
          </button>
        </div>
      )}
    </div>
  );
}
```

```tsx
export function LensReorder({
  value, onChange, max = 5,
}: { value: Lens[]; onChange: (next: Lens[]) => void; max?: number }) {
  const sensors = useSensors(
    useSensor(PointerSensor),
    useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates }),
  );
```

```ts
#!/usr/bin/env tsx
/**
 * Reads every src/app/api/ai/**\/route.ts and scores it on 11 calibration dimensions.
 * Writes a markdown report to docs/audits/tools-YYYY-MM-DD.md.
 *
 * Run: npx tsx scripts/audit-tools.ts
 */
import { readFileSync, writeFileSync, readdirSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';

export interface ToolScore {
  toolId: string;
  path: string;
  dimensions: {
    withCalibration: boolean;
    readsProfile: boolean;
    readsSituation: boolean;
    appliesLanguage: boolean;
    appliesRedLines: boolean;
    appliesAudience: boolean;
    usesSKCRetrieval: boolean;
    saveToolOutput: boolean;
    memoryBankTrace: boolean;
    zodSchema: boolean;
    creditsDeducted: boolean;
    profileVersionStamp: boolean;
  };
  score: number;
  notes: string[];
}

export function scoreRouteSource(toolId: string, src: string): ToolScore {
  const dims = {
    withCalibration: /\bwithCalibration\b/.test(src),
    readsProfile: /\b(calibration\.toolContext\.profile|getAnalystProfile)\b/.test(src),
    readsSituation: /\b(calibration\.toolContext\.situation|getSituationById|buildGraphContext)\b/.test(src),
    appliesLanguage: /outputConstraints\.language|calibration\.outputConstraints/.test(src),
    appliesRedLines: /redLine|outputConstraints\.redLine/.test(src),
    appliesAudience: /audienceTone|outputConstraints\.audienceTone/.test(src),
    usesSKCRetrieval: /SituationKnowledgeCore|retrieveForProfile|\bretrievalQuery\b/.test(src),
    saveToolOutput: /saveToolOutput\s*\(/.test(src),
    memoryBankTrace: /memoryBank|writeMemoryBank|vertex.*memory/i.test(src),
    zodSchema: /(z\.object|Output\.object|experimental_output)/.test(src),
    creditsDeducted: /checkAndDeductCredits|withCalibration/.test(src),
    profileVersionStamp: /profileVersion/.test(src),
  };
  const score = Object.values(dims).filter(Boolean).length;
  const notes: string[] = [];
  if (!dims.withCalibration) notes.push('Not wrapped with withCalibration — uses raw withAuth/withCredits.');
  if (!dims.saveToolOutput) notes.push('Does not call saveToolOutput — output lost.');
  if (!dims.zodSchema) notes.push('No Zod / Output.object schema validation detected.');
  return { toolId, path: '', dimensions: dims, score, notes };
}

function walkRoutes(dir: string, out: string[] = []): string[] {
  for (const ent of readdirSync(dir)) {
    const full = join(dir, ent);
    if (statSync(full).isDirectory()) walkRoutes(full, out);
    else if (ent === 'route.ts') out.push(full);
  }
  return out;
}

function toolIdFromPath(p: string): string {
  // src/app/api/ai/<tool>/route.ts → <tool>
  const m = p.match(/api[\\/]ai[\\/]([^\\/]+)[\\/]route\.ts$/);
  return m?.[1] ?? relative(process.cwd(), p);
}

function renderReport(results: ToolScore[]): string {
  const header = `# PRAXIS Tool Calibration Audit — ${new Date().toISOString().slice(0, 10)}\n\n` +
    `Audited ${results.length} AI routes. Score = count of 11 calibration dimensions satisfied.\n\n`;
  const table = ['| Tool | Score | withCal | SaveOut | VerStamp | SKC | Zod | Credits |',
                 '|---|---|---|---|---|---|---|---|']
    .concat(results.map(r => `| ${r.toolId} | ${r.score}/11 | ${mark(r.dimensions.withCalibration)} | ${mark(r.dimensions.saveToolOutput)} | ${mark(r.dimensions.profileVersionStamp)} | ${mark(r.dimensions.usesSKCRetrieval)} | ${mark(r.dimensions.zodSchema)} | ${mark(r.dimensions.creditsDeducted)} |`))
    .join('\n');
  const details = results.filter(r => r.notes.length).map(r => `### ${r.toolId}\n${r.notes.map(n => `- ${n}`).join('\n')}`).join('\n\n');
  return header + table + '\n\n## Per-tool notes\n\n' + details + '\n';
}

function mark(v: boolean): string { return v ? '✅' : '❌'; }

function main() {
  const root = join(process.cwd(), 'src', 'app', 'api', 'ai');
  const routes = walkRoutes(root);
  const results = routes.map(p => {
    const src = readFileSync(p, 'utf8');
    const score = scoreRouteSource(toolIdFromPath(p), src);
    score.path = relative(process.cwd(), p);
    return score;
  }).sort((a, b) => a.score - b.score);

  const dateStr = new Date().toISOString().slice(0, 10);
  const out = join(process.cwd(), 'docs', 'audits', `tools-${dateStr}.md`);
  writeFileSync(out, renderReport(results));
  console.log(`✓ Wrote ${out}`);
  console.log(`  ${results.filter(r => r.score >= 10).length}/${results.length} tools ≥10/11`);
}

// Run only when invoked directly
if (process.argv[1] && process.argv[1].endsWith('audit-tools.ts')) main();
```

```ts
#!/usr/bin/env tsx
/**
 * CI guard: fails if no audit report exists for today and the AI routes directory
 * has had changes in the last 24h. Encourages devs to re-run audit after tool edits.
 * Run: npx tsx scripts/verify-audit-fresh.ts
 */
import { readdirSync, statSync } from 'node:fs';
import { join } from 'node:path';
import { execSync } from 'node:child_process';

const audits = readdirSync(join(process.cwd(), 'docs', 'audits'));
const latestAudit = audits.filter(f => /^tools-\d{4}-\d{2}-\d{2}\.md$/.test(f)).sort().pop();
if (!latestAudit) {
  console.error('No audit report found in docs/audits/. Run: npx tsx scripts/audit-tools.ts');
  process.exit(1);
}

const auditDate = latestAudit.match(/^tools-(\d{4}-\d{2}-\d{2})/)?.[1];
if (!auditDate) { console.error('Bad audit filename:', latestAudit); process.exit(1); }

const changedSince = execSync(`git log --since="${auditDate} 00:00:00" --name-only --pretty=format: -- src/app/api/ai/`, { encoding: 'utf8' })
  .split('\n').map(l => l.trim()).filter(Boolean);

if (changedSince.length > 0) {
  console.error(`AI routes changed since last audit (${auditDate}):`);
  changedSince.forEach(f => console.error('  -', f));
  console.error('Re-run: npm run audit:tools && commit the new report.');
  process.exit(1);
}
console.log(`✓ Audit ${latestAudit} is current with routes.`);
```
