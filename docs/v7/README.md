# PRAXIS v7 Operating Packet

This folder contains the slice-control packet for the next PRAXIS simplification wave.

Use it when the work is specifically about the design-led, Ask PRAXIS-centered, mobile-first v7 app direction:

- `docs/roadmap/PRAXIS_DESIGN_LED_AGENTIC_APP_PLAN_2026-05-08.md`
- `docs/roadmap/PRAXIS_AGENTIC_MOBILE_FIRST_UX_PLAN_2026-05-08.md`
- `docs/roadmap/PRAXIS_TACIT_KNOWLEDGE_UX_REORGANIZATION_PLAN_2026-05-08.md`

## Files

- `AGENTS.md`: v7 Codex operating contract. It is stricter than the root repo handoff and applies to v7 slices.
- `PROMPTS.md`: paste-ready prompts for kickoff, resume, and skeptic-review sessions.
- `STATUS.md`: current slice ledger and owner questions.
- `SLICE_TEMPLATE.md`: template for adding a new slice under `docs/v7/SLICES/`.
- `OPEN_QUESTIONS.md`: decision log for unresolved product/schema/security questions.
- `DECISION_LOG.md`: append-only record of slice-level decisions.

## Precedence

Root `AGENTS.md` and `CLAUDE.md` remain the repo-wide operating docs.

For v7 slice work, future agents should also read this folder. If root guidance and v7 guidance conflict, use the safer rule: do not delete capabilities, do not weaken audits, and ask Giulio before touching schema, firewall, production data, Firestore rules, or top-level navigation decisions.
