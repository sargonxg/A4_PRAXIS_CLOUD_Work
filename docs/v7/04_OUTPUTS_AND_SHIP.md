# PRAXIS v7 Brief 04 - Outputs And Ship

Status: active brief

## Goal

Make PRAXIS output obviously useful and investor-demo ready.

The hero output is the Handover:

- what we believe
- why we believe it
- what changed
- what failed before
- what remains open
- what counsel stands now
- what the successor should ask first

## Output Surfaces

Reuse:

- MemoStudio
- DraftTab
- Boardroom synthesis
- reports and export routes
- citation chips
- evidence drawer
- trust metadata

## Output Rules

- Every generated output must show source/trust posture.
- Synthesized claims are labeled.
- Outputs save to a durable place.
- Exports should remain simple and reliable.
- Mobile must support reviewing and sharing outputs.

## Investor Demo

The demo path:

1. Open populated Situation.
2. Ask "what should I know first?"
3. Improve context from one source.
4. Generate handover.
5. Show citations, trust, and episode scope.
6. Export/share.

## Acceptance

- Handover works from demo data.
- Output can be opened in MemoStudio/Draft.
- Mobile can review and export/share.
- Landing/demo copy matches live capability.
