# PRAXIS v7 Brief 00 - Vision And Operating Principles

Status: active brief

## Vision

PRAXIS v7 is the design-led, Ask PRAXIS-centered simplification wave.

The product promise is:

> Select a workspace. Open a Situation. Ask PRAXIS. Produce a trusted handover.

The technical promise remains deeper:

- TACITUS policy context model
- episode-scoped analysis
- source receipts
- trust-marked claims
- Cognee/context creation
- graph and ontology structure
- calibrated AI routes
- core agentic workflows
- memos, drafts, boardroom, ACH, and exports

The UX must sell simplicity while preserving power.

## Operating Principles

1. **Simple first, powerful underneath.**
   The first screen should not expose the full technical architecture.

2. **Ask PRAXIS is the command plane.**
   Users should be able to ask, plan, act, review, and produce through one guided AI interface.

3. **Situations are the product object.**
   A Situation contains the TACITUS policy context model: stakeholders, stakes, episodes, hypotheses, tried-and-failed, open threads, and counsel.

4. **Cognee is infrastructure, not copy.**
   The product should say "context", "sources", "claims", "episodes", and "coverage", not backend memory jargon.

5. **Mobile is real.**
   Mobile must support asking, reviewing, uploading/saving sources, and generating handovers.

6. **No capability reset.**
   Workbench, Graph, Ontology, Tools, ACH, Boardroom, Memo Studio, Draft, and existing routes remain available. v7 reorganizes and wraps them.

7. **Review before mutation.**
   Agentic workflows can propose and stage changes, but canonical facts and graph writes remain review-gated.
