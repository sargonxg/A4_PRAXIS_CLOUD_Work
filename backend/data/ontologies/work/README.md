# Work ontologies (placeholder)

Future home for the eight work-ontology templates that complement the existing
domain ontologies under `backend/data/ontologies/specializations/`:

1. UN DPPA (political affairs desk)
2. Foreign ministry
3. Mediation NGO
4. Think tank
5. Sanctions desk
6. Humanitarian
7. Foreign correspondent
8. Academic

Domain ontologies say *what* a situation is about (armed conflict, sanctions,
human rights, etc.). Work ontologies say *how a practitioner works on it*
(the work episodes, deliverables, review cadences, and audience that shape a
brief, memo, dossier, or handover for a particular role).

Status: empty placeholder. Do not scaffold the eight templates without an
approved ADR.
